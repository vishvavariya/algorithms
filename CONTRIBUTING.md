# Contributing to Algorithms

First off, thank you for considering contributing to Algorithms! It's people like you that make this project a better learning tool for everyone.

## Code of Conduct

By participating in this project, you are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs

- **Check if the bug has already been reported** by searching on GitHub under [Issues](https://github.com/vishvavariya/algorithms/issues).
- If you can't find an open issue addressing the problem, [open a new one](https://github.com/vishvavariya/algorithms/issues/new). Be sure to include a title and clear description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

- Open a new issue with a clear title and description of the suggested enhancement.
- Explain why this enhancement would be useful to most users.

### Pull Requests

1. **Fork the repository** and create your branch from `main`.
2. **Install dependencies** with `npm install`.
3. **If you've added code that should be tested, add tests.**
4. **Ensure the test suite passes** with `npm test`.
5. **Run the build** with `npm run build` to ensure no TypeScript or Next.js errors.
6. **Issue a Pull Request** to the `main` branch.

## Styling and Design

This project follows a "Playful Tech" aesthetic. When adding new algorithms or UI elements:
- Use **Framer Motion** for purposeful animations.
- Stick to the **Tailwind CSS 4** design tokens established in `src/app/globals.css`.
- Ensure all components are responsive and handle mobile safe areas.

## Local Development

```bash
npm run dev
```

Thank you for contributing!
